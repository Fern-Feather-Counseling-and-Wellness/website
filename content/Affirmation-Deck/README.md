# Fern's Feels — Affirmation Deck

A 52-card self-care deck featuring Fern the crow and her crew.

## What's Included

| File | Description |
|------|-------------|
| `ferns-feels-52-cards.md` | All 52 cards with full content (front phrase + back truth/reflect/tiny step) |
| `print-layout-template.html` | Visual template for printing — replace illustrations with your art |
| `README.md` | This file |

## Card Categories

- **Punk Bird (Cards 1-13):** Boundaries & empowerment
- **Soft Grunge (Cards 14-26):** Healing & self-compassion  
- **Dark Cottagecore (Cards 27-39):** Nervous system & emotional regulation
- **Cute Weirdos Crew (Cards 40-52):** Community & growth

## How to Use

1. **Get artwork made** — Use the phrase descriptions to commission 52 unique card illustrations (or use the 4 style groups and repeat with variations)

2. **Print the deck:**
   - Use `print-layout-template.html` as a guide
   - Or export content to Canva/InDesign
   - Print double-sided on 13x19" cardstock (or 8.5x11" landscape, 2 per page)

3. **Sell or give away:**
   - Digital download (PDF with cut lines)
   - Printed deck (with box/tin)
   - Custom orders

## Quick Stats

- **52 cards** = 1 per week
- **Card size:** 3.5" x 2.5" (standard poker)
- **Front:** Illustration + phrase
- **Back:** THE TRUTH + REFLECT + TINY STEP
