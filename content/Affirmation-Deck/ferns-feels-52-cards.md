# Fern's Feels — 52 Card Affirmation Deck

## Structure Per Card

**FRONT:** Fern's phrase (bold, simple — fits with artwork style)  
**BACK:** 
- THE TRUTH: Psychoeducation about the nervous system / emotions
- REFLECT: Journaling prompt
- TINY STEP: One small actionable step

---

## Print Layout Notes

Each card: 2.5" x 3.5" (poker card size)

**FRONT:**  
- Fern or crew character illustration (center)  
- Phrase in bold, centered below illustration  

**BACK:**  
- Top: "THE TRUTH" — bold, dark text  
- Middle: "REFLECT" — italic  
- Bottom: "TINY STEP" — lighter/action color  

**Print template:** Create a 13-column x 4-row layout on 13x19" paper (or 8.5x11" with 2x4 layout, folded). Each card includes front on one side, back on the other, mirrored for double-sided printing.
