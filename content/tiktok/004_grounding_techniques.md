# Script 004: 5-4-3-2-1 Grounding (The One to Save)

**Hook (5 sec):** "Panic attack? Dissociating? Try this right now."

**Body (45 sec):**
The 5-4-3-2-1 technique. Use all five senses to anchor yourself to the PRESENT:

- **5** things you CAN SEE
- **4** things you can TOUCH
- **3** things you can HEAR
- **2** things you can SMELL
- **1** thing you can TASTE

It sounds simple because it IS simple. You're not "calming down" — you're giving your nervous system fresh data that says **right now, I'm safe.**

Print it. Save it. Share it with everyone who needs it.
