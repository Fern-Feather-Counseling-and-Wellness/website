# Neurobiology of Trauma – CEU Course

**Provider:** Fern & Feather Wellness Center

## Overview
This 12‑hour, 6‑module CEU‑approved course provides an in‑depth exploration of the neurobiological mechanisms underlying trauma and translates that knowledge into practical, evidence‑based interventions for mental‑health professionals.

## Course Structure
| Module | Title | File |
|--------|------------------------------|------------------------|
| 1 | Foundations of Trauma & the Brain | `module-1-foundations.md` |
| 2 | The Stress Response System – Biochemistry | `module-2-stress-response.md` |
| 3 | Neuroplasticity – Rewiring the Traumatized Brain | `module-3-neuroplasticity.md` |
| 4 | Memory Systems & Traumatic Recall | `module-4-memory.md` |
| 5 | Neurobiological Correlates of Trauma‑Related Disorders | `module-5-disorders.md` |
| 6 | Neurobiology of Evidence‑Based Interventions | `module-6-interventions.md` |

## Supporting Materials
- **Worksheets** (found in the `worksheets` subfolder):
  - Memory Mapping Worksheet (`memory-mapping-worksheet.md`)
  - Disorder Profile Worksheet (`disorder-profile-worksheet.md`)
  - Intervention Mapping Worksheet (`intervention-mapping-worksheet.md`)
- **Assessment** (`assessment.md`) – 30 multiple‑choice questions + final assignment.
- **Final Assignment** (`final-assignment.md`).
- **Syllabus** (`syllabus.md`).

## Completion Requirements
1. Complete all six modules (readings + worksheets).
2. Pass the assessment (≥80%).
3. Submit the 500‑word reflective final assignment.
4. Receive the CEU certificate (`certificate.md`).

## CEU Certificate
A template is provided in `certificate.md`. Upon successful completion, a personalized certificate will be generated and emailed to the participant.
