## Worksheet: Bottom‑Up / Top‑Down Decision Matrix

**Purpose:** To help clinicians decide whether to prioritize bottom‑up (somatic) or top‑down (cognitive) interventions based on client presentation.

**Instructions:** Assess the client's current state across each domain. Mark whether bottom‑up (B) or top‑down (T) is indicated, then decide.

| Domain | Client Presentation | Indicated Approach (B/T) | Rationale |
|--------|---------------------|---------------------------|-----------|
| **Arousal Level** | Hyperaroused (anxious, hypervigilant) | | |
| | Hypoaroused (shut down, dissociated) | | |
| **Window of Tolerance** | Narrow, easily flooded | | |
| | Wide, stable | | |
| **Verbal Access** | Able to articulate experience | | |
| | Difficulty verbalizing; somatic symptoms | | |
| **Cognitive Distortions** | Present, needs restructuring | | |
| | Minimal; primary somatic complaints | | |
| **Somatic Complaints** | Chronic tension, pain, bodily sensations | | |
| | Minimal; primarily emotional/cognitive | | |

### Decision Rules
- **If B (bottom‑up) is indicated** → Begin with grounding, breathwork, SE, yoga, or sensorimotor approaches to regulate physiology.
- **If T (top‑down) is indicated** → Use CBT, CPT, narrative therapy, or other cognitive approaches.
- **If both** → Sequence: stabilize with bottom‑up first, then transition to top‑down processing.

### Sample Plan
- **Client State:** Hyperaroused, narrow window, difficulty articulating → **Primary:** Bottom‑up (breathwork, grounding). **Secondary:** Top‑down (after window widens).
